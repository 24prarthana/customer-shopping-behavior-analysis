# Customer Shopping Behavior Analysis

## 📊 Project Overview

This is an end-to-end data analytics project focused on analyzing customer shopping behavior and generating business insights using:

- Python
- SQL
- Power BI

The project demonstrates the complete analytics workflow, from data preparation and exploratory analysis to SQL-based analysis and interactive dashboard creation.

---

## 🎯 Project Objective

The main objective of this project is to analyze customer shopping patterns and understand:

- Customer purchasing behavior
- Sales and revenue by product category
- Customer distribution by age group
- Subscription behavior
- Customer satisfaction
- Shipping preferences
- Average purchase amount
- Sales performance across different customer segments

## 🔄 Project Workflow

### 1. Data Preparation using Python

Python was used to clean and prepare the customer shopping dataset for analysis.

Tasks included:

- Data type validation

- Exploratory analysis

### 2. Data Analysis using SQL

SQL was used to perform business-oriented analysis on the dataset.

- Purchase behavior

### 3. Interactive Dashboard using Power BI

The cleaned and analyzed data was visualized using Power BI.

- **3.9K Customers**
- **₹59.76 Average Purchase Amount**
- **3.75 Average Review Rating**
- **73% Non-Subscribers**
- **27% Subscribers**

The dashboard provides insights into:

- Sales by category

- Shipping preferences

Interactive filters were added for:

- Gender

---

## 📈 Key Insights

The dashboard provides a high-level view of customer purchasing behavior and allows users to interactively explore different customer segments.

Some of the key observations include:

- The customer base contains approximately 3.9K customers.
- The average purchase amount is ₹59.76.
- The average customer review rating is 3.75.
- Non-subscribers represent a larger proportion of customers than subscribers.
- Clothing generates the highest revenue among the analyzed categories.
- Customer sales and revenue vary across different age groups.
